# Buildcraft Reforged

BuildCraft's Minecraft 1.6.4 machines, engines, pipes and builders, rebuilt for NeoForge on Minecraft 26.x, with Forge
Energy, a redesigned rate-based transport system, overheat alarms and a status panel on every machine.

Status: early development (0.x). Nothing playable yet. See [docs/PLAN.md](docs/PLAN.md) for the plan and phases.

## Building

Needs JDK 25.

```bash
./gradlew build          # jar in build/libs/
./gradlew runClient      # start a development client
```
